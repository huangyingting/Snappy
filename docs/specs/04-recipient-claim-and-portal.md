# Recipient claims and delivery

High-entropy invitation links grant access to one gift. Code lookup also requires the invitation's email. Saved address books require an authenticated, verified recipient account; a bearer link alone cannot read them.

Claims validate budget, stock, approved vendor, expiration, and supported region. The transaction creates one order and reconciles inventory and escrow. Pre-dispatch delivery edits and swaps require ownership; higher-priced swaps cannot overdraw the sender.

Charity selections are pending transfer until an administrator records settlement.
