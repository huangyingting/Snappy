# Workspace UI and real data

Preserve the Atelier visual system while rendering only persisted business data. Empty catalogs, campaigns, ledgers, and fulfillment queues must be understandable. Do not prefill real-action forms with sample people, products, balances, or tracking numbers.

Public catalog cards show approved, available inventory. Authentication has no persona switcher. Product images come from the vendor, not sample presets. Logistics views distinguish vendor-entered checkpoints and unknown carrier data.
